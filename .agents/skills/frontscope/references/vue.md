# Vue: leitura condicional

Confirme versão e uso de Options/Composition API. Siga props/emits, refs, computed, watchers e ciclo de vida conforme o código real. Ao suspeitar perda de reatividade por desestruturação, confira versão/compilação e contexto: macros podem mudar a semântica. Demonstre o fluxo afetado antes de reportar.

Composable local pode isolar efeitos ou estado de um único consumidor; transformação pura não exige composable. Distinga computed derivado de efeitos em watch/watchEffect e verifique limpeza. Não traduza automaticamente dependências de hooks React para Vue nem recomende store global para um estado local coeso.
